# 개인 Open Questions

현재 지속적으로 관리할 미결 Question 없음. 로컬 운영문서 적용의 차단도 없음.

새 질문이 세션을 넘어 보존될 때만 [Question schema](open-questions/README.md)로 기록한다. 실제 작업을 막는 경우만 `blocks`를 둔다. 팀 확인·미확정 API/DB·권한 사항은 개인 확정 Decision으로 바꾸지 않는다.

Git 전달 단계가 현재 요청에 포함되지 않은 경우 그것을 필수 Task 실패나 미결 Question으로 만들지 않는다. PR·merge가 요청되면 그 승인된 대상·단계까지 진행한다. 조건부 Workflow 검토는 [확장 기준](../docs/operations/workflow-evolution.md)이 소유한다.
